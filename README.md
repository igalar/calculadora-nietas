# Calculadora de las nietas

Calculadora que habla con la voz de cada nieta y les ayuda a aprender las tablas de multiplicar.
App web instalable (PWA) que funciona sin internet, sin cuentas, anuncios ni analítica.

**Abrir la app:** https://igalar.github.io/calculadora-nietas/

Instrucciones completas en [LEEME.md](LEEME.md).
